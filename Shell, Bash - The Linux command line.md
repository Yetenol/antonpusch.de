
Liste Blockspeichermedien (Festplatten, SSD) auf
```shell
lsblk
```

List files and their size
```bash
ls -l --block-size=M
```

# Navigieren im Dateisystem

Liste Verzeichnisinhalt auf
```
ls
```

Aktuelles Verzeichnis ausgeben
```
pwd
```
