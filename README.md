# Static Site Generator for antonpusch.de

## Dependencies

- See [instructions](https://quartz.jzhao.xyz/)

Node.js (LTS)

```powershell
winget install -e OpenJS.NodeJS.LTS
```

- Update npm tool
  ```powershell
  npm audit fix
  ```

- Install node packages
  ```powershell
  npm i
  ```

# Update

- See [instructions](https://quartz.jzhao.xyz/upgrading)

```powershell
npx quartz update
```
