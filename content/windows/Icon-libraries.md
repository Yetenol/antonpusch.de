contains lots of icons, used almost everywhere in windows 10. it has icons for different types of folders, hardware devices, actions, and so on
```cmd
%systemroot%\system32\imageres.dll
```

also has lots of icons used in various parts of windows 10. together with imageres.dll, shell32.dll hosts one of the largest icon collections in windows 10
```cmd
%systemroot%\system32\shell32.dll
```

contains old-style icons that were used for all kinds of things, since windows 95
```cmd
%systemroot%\system32\pifmgr.dll
```

has a few icons used mainly in file explorer
```cmd
%systemroot%\explorer.exe
```

has a set of icons that are used mainly for the accessibility features in windows 10
```cmd
%systemroot%\system32\accessibilitycpl.dll
```

contains icons for hardware devices and resources
```cmd
%systemroot%\system32\ddores.dll
```

has a few gaming related icons
```cmd
%systemroot%\system32\gameux.dll
```

is another file that contains old-style icons, used by microsoft in old windows versions
```cmd
%systemroot%\system32\moricons.dll
```

is yet another file with old looking icons, which we believe were designed mainly for computer management related settings
```cmd
%systemroot%\system32\mmcndmgr.dll
```

has icons with various audio resources, like speakers, headphones, microphones etc
```cmd
%systemroot%\system32\mmres.dll
```

has icons for network related settings and features
```cmd
%systemroot%\system32\netcenter.dll
```

contains icons for all kinds of network connections and associated hardware or technologies. for instance, inside it, you'll find icons for bluetooth or for wireless routers
```cmd
%systemroot%\system32\netshell.dll
```

another .dll file with a few network related icons
```cmd
%systemroot%\system32\networkexplorer.dll
```

has icons for network related settings (ethernet or wireless status, network locations, etc.)
```cmd
%systemroot%\system32\pnidui.dll
```

has a few icons for different kinds of sensors. while most of them look similar, their details indicate things like temperature, power, wind etc
```cmd
%systemroot%\system32\sensorscpl.dll
```

has icons used for the setup wizard of various hardware devices
```cmd
%systemroot%\system32\setupapi.dll
```

contains icons used for media devices, files, folders, and so on
```cmd
%systemroot%\system32\wmploc.dll
```

has icons for some portable devices and battery indicators
```cmd
%systemroot%\system32\wpdshext.dll
```

includes various classic icons from older versions of windows
```cmd
%systemroot%\system32\compstui.dll
```

contains the icons used in internet explorer
```cmd
%systemroot%\system32\ieframe.dll
```

contains the icons for disk management
```cmd
%systemroot%\system32\dmdskres.dll
```

includes icons for network services
```cmd
%systemroot%\system32\dsuiext.dll
```

stores icons used for remote desktop connections
```cmd
%systemroot%\system32\mstscax.dll
```

has icons for various imaging hardware devices, like scanners and cameras
```cmd
%systemroot%\system32\wiashext.dll
```
