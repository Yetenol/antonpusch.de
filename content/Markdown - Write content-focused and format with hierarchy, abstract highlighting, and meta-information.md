## Escape Special Character  
  
| Character         | Escape Code                              | Name                |  
| ----------------- | ---------------------------------------- | ------------------- |  
| \                 | `\\\\`                                   | backslash           |  
| &#96;             | <code>&#92;&#96;</code> <br> `&#96;`     | backtick            |  
| &#96;echo &#96;5&#96; | <code>&#96;&#96; &#96; &#96;&#96;</code> | backtick in code    |  
| \*                | `\*`                                     | asterisk            |  
| \_                | `\_`                                     | underscore          |  
| \{ \}             | `\{` `\}`                                | curly braces        |  
| \[ \]             | `\[` `\]`                                | brackets            |  
| \< \>             | `\<` `\>`                                | angle brackets      |  
| \( \)             | `\(` `\)`                                | parentheses         |  
| \#                | `\#`                                     | pound sign          |  
| \+                | `\+`                                     | plus sign           |  
| \-                | `\-`                                     | minus sign (hyphen) |  
| \.                | `\.`                                     | dot                 |  
| \!                | `\!`                                     | exclamation mark    |  
| &#124;            | <code>&#92;&#124;</code> <br> `&#124;`   | pipe                |
