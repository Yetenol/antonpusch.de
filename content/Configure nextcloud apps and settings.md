# New user  
  
- Open [Profiles > Users](https://plutos.hopto.org/index.php/settings/users)  
- Create a new user with your preferred name  
    - `anton` =: username  
    - `admin` =: Add user to group  
- Log in with new user  
- Delete old default user `ncp`  
- Open [Personal settings > Personal info](https://plutos.hopto.org/index.php/settings/user)  
- Upload profile picture  
  
# Two-Factor Authentication  
  
- Install [Two-Factor TOTP Provider](https://plutos.hopto.org/settings/apps/installed/twofactor_totp)   
- Open [Personal settings > Security > Two-Factor Authentication](https://plutos.hopto.org/settings/user/security)   
- [x] Enable TOTP  
- Save TOTP secret  
- Generate backup codes  
  
# Theming  
  
- Open [Administration settings > Theming](https://plutos.hopto.org/settings/admin/theming)   
- `PlutosCloud` =: Name  
- `https://antonpusch.de/` =: Web link  
- `Anton's cloud infrastructure` =: Slogan  
- `#FFD580` =: Color  
  
# Apps  
  
- Disable [User status](https://plutos.hopto.org/settings/apps/installed/user_status)   
- Enable [Forms](https://plutos.hopto.org/settings/apps/featured/forms)
