PDFsam is a [office](install%20office%20apps.md.md) app. Merge, split, extract pages, rotate and mix your PDF files.

- Invoke the installer listed on Windows Package Manager:
  ```powershell
  winget install -e PDFsam.PDFsam
  ```
- Download the [latest release](https://github.com/torakiki/pdfsam/releases/latest) of its source code [repository](https://github.com/torakiki/pdfsam) on GitHub
- Download it from the [publisher's website](https://pdfsam.org/pdfsam-basic/)
