AusweisApp2 is a [office](install%20office%20apps.md.md) app. AusweisApp2 is a software that you install on your smartphone, computer or tablet in order to read out your ID card and to be able to identify yourself digitally. In addition, AusweisApp2 enables encrypted data exchange between the ID card and the online service where you want to identify yourself.

- Invoke the installer listed on Windows Package Manager:
  ```powershell
  winget install -e Governikus.AusweisApp2
  ```
- Download it from the [publisher's website](https://www.ausweisapp.bund.de/download)


- [ ] Auto start AusweisApp2 after boot
- Connect smartphone and PC in the same WiFi network
- ON THE SMARTPHONE: `Remote > Start pairing`
- ON THE PC: Pair the available smartphone
- Test a Personalausweis
