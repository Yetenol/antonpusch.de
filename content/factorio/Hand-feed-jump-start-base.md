# Hand-feed base

Burner miners output directly into furnaces 
- 16 Iron Smelters
- 4 Copper Smelters
- 4 Stone miners
- 16 Coal miners

Generate Power
- tile 1 boiler and 2 Steam engines next to each other
- Assemble items from hand-feed chests
    - Green Circuits, Red Science, Belts, Inserter, Assembler, Green Science

# Jump start base

Electric miners output to belt which feed furnace array
- Start with stone furnaces and upgrade to steel furnaces

Get all building items for the real base in one place
- Inserters, Assembler, Belts
- Complete all red and green science

Add steel and stone production
- Better assemblers, power poles
- Pathways
